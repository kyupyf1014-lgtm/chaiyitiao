# 拆一条 · 第一版交互设计

把一条参考短视频整理成可以对照、校对和导出的分镜脚本。

一个面向个人创作者的短视频分镜拆解工作台，可运行的 V0.1 前端交互原型。

**当前支持本地视频播放、手动分镜校对和导出；尚未接入真实 AI 分析服务。**

## 运行

无需安装前端依赖，使用 Node.js 18 或以上版本：

```sh
npm run dev
```

默认地址为 `http://127.0.0.1:4173`。端口被占用时可指定：

```sh
PORT=4186 npm run dev
```

服务器只监听本机地址。支持 MP4 范围请求，方便跳转视频时间。

## 已实现

- 示例工作台：6 个分镜、2 处待核实、独立的完整口播和内容结构视图。
- 本地视频选择与拖入：MP4、MOV、WebM；200 MB 大小校验；读取真实时长、播放视频。
- 点击分镜代表画面或时间，定位原片；播放时同步突出当前分镜。
- 直接编辑画面、口播、屏幕文字；详情窗口可修改时间、拍摄信息、内容作用、待核实项和约值标记。
- 手动添加分镜、在完整分镜序列中拆出新镜头；校验越界与重叠；本地原片自动截取代表画面。
- 筛选待核实项、标记已校对、显示校对进度。
- 草稿保存到浏览器；示例与本地草稿可切换；重新选择同名同长原视频时保留草稿。
- CSV、Markdown、TXT 下载与表格复制。CSV 使用 UTF-8 BOM，并对公式前缀做文本处理。
- 桌面与窄屏布局；键盘可操作的标签页和弹窗。

## 当前边界

- **没有接入 AI 服务。** 上传真实视频后创建手动草稿，不会伪造识别结果。
- 示例视频是项目自制的 36 秒插画演示片，无音频；口播文字、内容作用和结构分析为虚构演示数据。
- 草稿保存在当前浏览器、当前来源地址中，保存一个示例草稿和最近一个本地视频草稿。上传另一个不同视频会替换本地草稿槽位，重要内容应先导出。
- 视频文件不上传、不持久保存；刷新本地项目后，需要重新选择原片。浏览器不支持的编码需转为 H.264 MP4 等可播放编码。
- 重新关联目前使用文件名与时长检查，后续正式版应增加文件摘要校验。
- 原型不会测量或宣称 AI 准确率、转写速度或效率提升。
- 导出文件含文本与核实状态，不嵌入镜头截图；CSV 可由 Excel / 飞书表格打开，本版不提供原生 XLSX。
- 内容结构分析在独立视图中编辑；本地手动项目的结构分析能力留待下一版接入。

完整产品与交互说明见 [DESIGN.md](DESIGN.md)。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 工作台、上传、分镜详情、导出、指南 |
| `styles.css` | 视觉样式与响应式布局 |
| `app.js` | 项目数据、视频联动、校对、保存和导出 |
| `server.mjs` | 无依赖的本地静态服务器 |
| `assets/` | 原创图标、分镜插画与演示视频 |
| `scripts/make_demo.py` | 示例素材生成源文件（需要 Pillow 与 FFmpeg，仅重新生成素材时使用） |

项目代码与演示插画均为本项目制作，未复制参考项目的代码。
